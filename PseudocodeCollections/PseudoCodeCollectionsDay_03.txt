START
Define CLASS Book with:
    - title
    - yearPublished
    - rating

Create a LIST<Book> library

Add books to library:
    Book("Book A", 2018, 4.8)
    Book("Book B", 2012, 4.7)
    Book("Book C", 2019, 4.3)
    Book("Book D", 2021, 4.9)

Use STREAM with FILTER:
    condition → yearPublished > 2015 AND rating > 4.5

Collect the filtered books into a new list

For each book in filtered list:
    PRINT book.title + " (" + yearPublished + ") rating " + rating
END
