START
Define CLASS Item with:
    - name
    - price

Create a LIST<Item> called cart

Add some items to the cart:
    Item("Laptop", 50000)
    Item("Mouse", 800)
    Item("Keyboard", 1500)

Define a GENERIC METHOD calculateTotal(cart):
    total = 0
    FOR each item in cart:
        total = total + item.price
    RETURN total

Call calculateTotal(cart)
Display "Total Price = " + total
END
